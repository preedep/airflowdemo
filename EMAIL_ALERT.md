## SMTP Configuration

### Environment Variables Setup

Add these environment variables to your `docker-compose.yaml`:

```yaml
# Email Templates
AIRFLOW__EMAIL__SUBJECT_TEMPLATE: /opt/airflow/templates/email_subject_template.txt
AIRFLOW__EMAIL__HTML_CONTENT_TEMPLATE: /opt/airflow/config/email_body_template.html

# SMTP Configuration
AIRFLOW__SMTP__SMTP_HOST: ${SMTP_HOST}
AIRFLOW__SMTP__SMTP_PORT: ${SMTP_PORT}
AIRFLOW__SMTP__SMTP_STARTTLS: ${SMTP_STARTTLS}
AIRFLOW__SMTP__SMTP_SSL: ${SMTP_SSL}
AIRFLOW__SMTP__SMTP_USER: ${SMTP_USER}
AIRFLOW__SMTP__SMTP_PASSWORD: ${SMTP_PASSWORD}
AIRFLOW__SMTP__SMTP_MAIL_FROM: ${SMTP_MAIL_FROM}
AIRFLOW__EMAIL__FROM_EMAIL: ${AIRFLOW_EMAIL_FROM}
AIRFLOW__EMAIL__EMAIL_BACKEND: airflow.utils.email.send_email_smtp
```

### Environment Variables (.env file)

Create a `.env` file with your SMTP settings:

```bash
# Gmail Configuration
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_STARTTLS=true
SMTP_SSL=false
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-app-password
SMTP_MAIL_FROM=your-email@gmail.com
AIRFLOW_EMAIL_FROM=your-email@gmail.com

# Outlook Configuration (Alternative)
# SMTP_HOST=smtp-mail.outlook.com
# SMTP_PORT=587
# SMTP_STARTTLS=true
# SMTP_SSL=false
```

## SMTP Connection Setup

### What is SMTP Connection?

SMTP Connection in Airflow is a configuration stored in Airflow's Connection store that provides:

- **Secure credential management** - No need to hardcode passwords in DAGs
- **Reusability** - One connection can be used across multiple DAGs
- **Centralized management** - Modify settings in one place
- **Encryption support** - Airflow automatically encrypts sensitive data

### Default SMTP Connection

**`smtp_default`** is the standard Connection ID that Airflow uses for email sending:

- Airflow automatically looks for a connection named `smtp_default`
- If not found, it falls back to environment variables
- Can be overridden by specifying `email_conn_id` in DAG configuration

### Creating SMTP Connection

#### Method 1: Using Shell Script (Recommended)

Use the `add_smtp_default.sh` script for automated connection creation:

```bash
# Run script to create smtp_default connection
./add_smtp_default.sh

# Or specify custom connection ID
./add_smtp_default.sh my_smtp_connection
```

#### Method 2: Using Airflow CLI

```bash
# Create SMTP connection via CLI
docker-compose exec airflow-webserver airflow connections add \
  --conn-id smtp_default \
  --conn-type smtp \
  --conn-host smtp.gmail.com \
  --conn-port 587 \
  --conn-login your-email@gmail.com \
  --conn-password your-app-password \
  --conn-extra '{"use_tls": true, "use_ssl": false}'
```

#### Method 3: Using Airflow Web UI

1. Navigate to Airflow Web UI → Admin → Connections
2. Click "Add a new record"
3. Fill in the details:
   - **Connection Id**: `smtp_default`
   - **Connection Type**: `SMTP`
   - **Host**: `smtp.gmail.com`
   - **Port**: `587`
   - **Login**: `your-email@gmail.com`
   - **Password**: `your-app-password`
   - **Extra**: `{"use_tls": true, "use_ssl": false}`

## Email Templates

### HTML Email Body Template

Create `email_body_template.html` in your config directory:

```html
<html>
  <body>
    <h2>🔔 Airflow Task Notification</h2>
    <table border="1" cellpadding="5" cellspacing="0" style="border-collapse: collapse;">
      <tr><td><strong>DAG:</strong></td><td>{{ ti.dag_id }}</td></tr>
      <tr><td><strong>Task:</strong></td><td>{{ ti.task_id }}</td></tr>
      <tr><td><strong>Status:</strong></td><td>{{ ti.state }}</td></tr>
      <tr><td><strong>Try:</strong></td><td>{{ ti.try_number }} / {{ ti.max_tries + 1 }}</td></tr>
      <tr><td><strong>Execution Date:</strong></td><td>{{ ts }}</td></tr>
      {% if exception %}
      <tr><td><strong>Exception:</strong></td><td><pre>{{ exception }}</pre></td></tr>
      {% endif %}
    </table>
    <p><em>Generated by Airflow at {{ ts }}</em></p>
  </body>
</html>
```

### Email Subject Template

Create `email_subject_template.txt` in your templates directory:

```txt
[Airflow] {{ ti.dag_id }}.{{ ti.task_id }} {{ ti.state }} - {{ ts }}
```

## DAG Examples

### Example 1: Basic Failure Alert DAG (`scb_ap1234_notify_test_v4.py`)

This DAG demonstrates automatic failure notifications:

```python
import pendulum
import logging
from airflow import DAG
from airflow.providers.standard.operators.python import PythonOperator

# Enable debug logging for email troubleshooting
logging.getLogger("smtplib").setLevel(logging.DEBUG)
logging.getLogger("airflow.utils.email").setLevel(logging.DEBUG)

default_args = {
    "owner": "airflow",
    "email": ["your-email@gmail.com"],
    "email_on_failure": True,
    "email_on_retry": True,  # Optional: enable retry notifications
}

def fail_task():
    """Intentionally fail to trigger email notification"""
    raise ValueError("Intentional failure to trigger email notification")

with DAG(
    dag_id="scb_ap1234_notify_test_v4",
    start_date=pendulum.datetime(2024, 1, 1, tz="UTC"),
    schedule="@once",
    catchup=False,
    default_args=default_args,
    tags=["scb_ap1234", "v4", "notify"],
    description="Test DAG for email failure notifications",
) as dag:
    
    fail_and_notify = PythonOperator(
        task_id="fail_and_notify",
        python_callable=fail_task,
    )
```

### Example 2: Direct SMTP Email DAG

This DAG sends emails directly using `send_email()` function:

```python
from airflow import DAG
from airflow.operators.python import PythonOperator
import pendulum
from airflow.utils.email import send_email
import logging

logging.getLogger("smtplib").setLevel(logging.DEBUG)
logging.getLogger("airflow.utils.email").setLevel(logging.DEBUG)

def send_test_email():
    """Send a test email directly"""
    send_email(
        to=["your-email@gmail.com"],
        subject="✅ Direct SMTP Email from Airflow",
        html_content="""
        <h2>Test Email from Airflow</h2>
        <p>This email was sent directly using <code>airflow.utils.email.send_email()</code></p>
        <p><strong>Timestamp:</strong> {{ ts }}</p>
        """
    )
    return "Email sent successfully"

with DAG(
    dag_id="scb_ap1234_notify_test_direct_smtp_email",
    start_date=pendulum.datetime(2024, 1, 1, tz="UTC"),
    schedule="@once",
    tags=["scb_ap1234", "direct_email", "test"],
    catchup=False,
    description="Test DAG for direct email sending",
) as dag:
    
    send_email_task = PythonOperator(
        task_id="send_email_task",
        python_callable=send_test_email,
    )
```

```bash

docker-compose exec airflow-webserver python3 -c "

from email.mime.text import MIMEText

server = smtplib.SMTP('smtp.gmail.com', 587)
server.starttls()
server.login('your-email@gmail.com', 'your-app-password')
print('SMTP connection successful!')
server.quit()
"
```

